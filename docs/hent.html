Get Rundbordet for your computer

Rundbordet lets several AI models work together on your task, so you can follow along and decide along the way. The program lives on your own computer. Version 0.45.0.

How to get started

  1. Find your computer in the table below and press Get. On a Mac and not sure about the chip: choose the Apple menu → About This Mac. If it says Apple M (for example M1 or M2), choose Apple silicon; if it says Intel, choose Intel.
  2. Mac: open the downloaded file and drag Rundbordet to the Applications folder. Windows: run the installer.
  3. Open Rundbordet. The programs are not signed yet, so Mac or Windows shows a warning the first time. Mac: on macOS 15 or later open System Settings → Privacy & Security and choose Open Anyway; on older versions right-click the app and choose Open. Windows (SmartScreen): choose More info and Run anyway.
  4. You will need a key for an AI service, a kind of password. It is not part of the program, and you pay the service for what you use. The program has a link to get one. If you want to see it first, use the demo: it needs no key.

Read before you install

The programs are not signed yet. That is why Mac and Windows show a warning the first time (see step 3). The Windows version has not been tested by us on a Windows machine yet. The Linux archive (x64) has been tried on Omarchy (Arch with Hyprland) and works there. That is not proof for other Linux distributions.

The desktop version has what the browser does not: your own folders (IN and OUT), keys in the computer's keyring, Save to git and read-aloud.

For the curious: check the file

The checksum (SHA-256) shows that the file is the one we published. On a Mac: open Terminal and type shasum -a 256 followed by a space and the file's path (drag the file into the window), then compare with the number here. On Windows: certutil -hashfile <file> SHA256.

Free use, your own costs, licence and introductory courses

Free to download and use. The program can be downloaded and used for free, also without a licence. There is a recorded demo that needs no key.

Your own API key and costs. You use your own API key and pay the model provider directly for the usage. A ChatGPT or Claude subscription does not in itself give an API key. The price depends on the model, the material and the number of calls; more seats and repeats can raise it.

Update licence. A one-time paid licence gives access to the update function in the app (check for and download new versions; the app downloads and verifies the file but does not install it for you). The program works without a licence. The price and how to pay have not been published here yet.

Introductory courses. Paid introductory courses are offered, where participants work with their own tasks and take a reusable table home. Sign-up and price have not been published here yet.
