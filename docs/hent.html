Read before you install

The programs are not signed yet. Mac shows a warning the first time: on macOS 15 or later open System Settings → Privacy & Security and choose Open Anyway; on older versions right-click the app and choose Open. Windows may show SmartScreen: choose More info and Run anyway. The Windows version has not been tested by us on a Windows machine yet. The Linux archive (x64) has been tried on Omarchy (Arch with Hyprland) and works there. That is not proof for other Linux distributions. Check the file's checksum before you open it.

Free use, your own costs, licence and introductory courses

Free to download and use. The program can be downloaded and used for free, also without a licence. There is a recorded demo that needs no key.

Your own API key and costs. You use your own API key and pay the model provider directly for the usage. A ChatGPT or Claude subscription does not in itself give an API key. The price depends on the model, the material and the number of calls; more seats and repeats can raise it.

Update licence. A one-time paid licence gives access to the update function in the app (check for and download new versions; the app downloads and verifies the file but does not install it for you). The program works without a licence. The price and how to pay have not been published here yet.

Introductory courses. Paid introductory courses are offered, where participants work with their own tasks and take a reusable table home. Sign-up and price have not been published here yet.
